三、定位框为什么加深了

原来的 #C0B0FF 在深底上很亮眼，放到 #F4F1FD 上却只有约 1.6:1，那条行列十字线会基本消失。所以定位框改成同色相的 #8B79E8——仍是紫罗兰，但在浅底上稳定达到 3.14:1（图形元素的可辨识门槛为 3:1）。

而 #F4F1FD 正是从这一族紫罗兰里取的极浅调：色相约 255°，与定位框、界面 #343061 同源，所以深色外壳、浅色画布、紫色定位框三者不会互相打架。

注意：DocColor 是全局「文档背景」，不只影响 Calc——Writer 的纸张、Draw 的页面也会一起变浅紫。LibreOffice 没有单独的「Calc 单元格背景」配置项，这是主题框架的固有限制。相应地正文默认色 FontColor 也已同步改成深色，否则白字会看不见。

四、应用与回退

  1. 扩展已覆盖安装为 v1.1.0，当前主题仍是 Violet Dusk，重启 LibreOffice 即生效。
  2. 不要勾选「使用白色文档背景」——一旦勾上，画布会被强制变纯白，浅紫底色失效。
  3. 想再调：改 build-violet-dusk-theme.py 里的 DOC 字典 → 重跑脚本 → 关闭 LO → unopkg add 覆盖安装。
  4. 回退到全深色：外观页切回 Dracula 即可（扩展仍在）。
